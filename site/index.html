CST Studio’yu
MCP istemcinize bağlayın.

01 / Yaklaşım

Yerel çalışır.
Kontrol sizde kalır.

Sunucu, MCP istemcisi ile CST’nin Python otomasyon katmanı arasında açık bir köprü kurar. CST’yi kendiliğinden başlatmaz; bağlantıyı cst_connect çağrısıyla açıkça siz başlatırsınız.

↳

Açık bağlantı adımı

İstemci sunucuyu yükledikten sonra cst_connect aracını çağırırsınız. Böylece kurulum sırasında CST veya başka bir istemci beklenmedik biçimde açılmaz.

⌁

Yerel standart girdi ve çıktı

MCP mesajları standart girdi ve çıktı üzerinden taşınır. CST kurulumu ve proje dosyaları Windows makinenizde çalışır.

02 / Kurulum

Dört adımda
yerel bağlantı.

Aşağıdaki akış Windows PowerShell içindir. Örnek yollar temsilidir; kendi kurulum ve çalışma klasörünüzü yazın.

  1. 01

    Depoyu ve sanal ortamı hazırlayın

    PowerShell
    git clone https://github.com/ismailakdag/cst-studio-mcp.git
cd cst-studio-mcp
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
  2. 02

    CST Python yolunu kontrol edin

    CST sürümünüzün AMD64\python_cst_libraries klasörünü bulun. Yapılandırmadaki CST_PATH ana CST klasörünü, PYTHONPATH ise bu Python kitaplığı klasörünü göstermelidir.

  3. 03

    MCP istemcinize ekleyin

    İstemcinize uygun örneği seçin. Her iki yapılandırma da CST bağlantısını siz cst_connect çağrısını verene kadar kapalı tutar.

    Claude Desktop / Cursor · JSON
    {
  "mcpServers": {
    "cst-studio": {
      "command": "C:\\path\\to\\cst-studio-mcp\\.venv\\Scripts\\cst-studio-mcp.exe",
      "args": [],
      "env": {
        "CST_PATH": "C:\\Program Files\\CST Studio Suite 2026",
        "CST_WORK_DIR": "C:\\cst_projects",
        "CST_VERSION": "2026",
        "CST_CONNECT_MODE": "manual",
        "PYTHONPATH": "C:\\Program Files\\CST Studio Suite 2026\\AMD64\\python_cst_libraries"
      }
    }
  }
}
    Codex · config.toml
    [mcp_servers.cst-studio]
command = 'C:\path\to\cst-studio-mcp\.venv\Scripts\cst-studio-mcp.exe'
args = []

[mcp_servers.cst-studio.env]
CST_PATH = 'C:\Program Files\CST Studio Suite 2026'
CST_WORK_DIR = 'C:\cst_projects'
CST_VERSION = '2026'
CST_CONNECT_MODE = 'manual'
PYTHONPATH = 'C:\Program Files\CST Studio Suite 2026\AMD64\python_cst_libraries'

    Codex yapılandırmasının güncel ayrıntıları için resmî MCP belgesini açın ↗.

  4. 04

    İstemciyi yenileyin ve bağlanın

    MCP istemcisini yeniden yükleyin. Araçlar göründüğünde cst_connect çağrısını verin; bağlantıyı bitirmek için cst_disconnect kullanın.
