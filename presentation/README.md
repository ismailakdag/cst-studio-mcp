# Proje sunumu

[index.html](index.html) tek başına çevrimdışı açılır; fontlar HTML içinde gömülüdür. Font lisansları bu klasördedir. Sunum görünümü ve Yazdır / PDF seçenekleri vardır. Bu sayfa doğrulama kaydının anlık görüntüsüdür, canlı durum paneli değildir.

[project.json](project.json) içerik kaynağı; [manifest.json](manifest.json) dosya karmalarını tutar. Ortak üretici araştırma çalışma alanındaki tools/presentations altındadır.
